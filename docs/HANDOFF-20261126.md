## 6. Dựng lại môi trường trên máy mới
```bash
git clone git@github.com:fossbk-spec/biomedical-rdm.git
git clone git@github.com:fossbk-spec/HDBS.git
git clone git@github.com:fossbk-spec/biomedical-rdm-course.git   # nếu cần sửa web
# RDM: chỉ cần Python 3.11 trở lên (thư viện chuẩn; CI dùng 3.12); Quarto và Node cho web
python scripts/check_structure.py --check          # kiểm tra nền
# HDBS: tạo venv rồi cài đúng phụ thuộc (pydantic 2.x, rapidfuzz, ...)
python -m venv .venv && .venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python scripts/ci_checks.py all
gh auth status
```
- Biến môi trường (không bao giờ ghi vào repo hay trò chuyện): `OPENALEX_API_KEY`, `SEMANTIC_SCHOLAR_API_KEY`, `GEMINI_API_KEY`.
- Máy chặn TLS (Avast): `pip install --cert "<pem của Avast>"`. Đẩy qua SSH (`git@github.com:`).
- Kiểm tra trước khi báo xong ở RDM: `check_structure`, `check_glossary`, `check_crossrefs`, `check_quizzes`, `check_volatile` (đều `--check`), `build_bib.py --check`, `audit_references.py` (rồi `git checkout -- references/AUDIT-REPORT.md` nếu chỉ đổi dòng ngày), `git diff --check`; ghi exit code thật.
- Codex CLI không nằm trong PATH: `%LOCALAPPDATA%\OpenAI\Codex\bin\<hash>\codex.exe`, dùng `codex exec -s read-only` để review chỉ đọc; kết quả của nó có thể sai (đã thấy nó khẳng định nhầm `_site/` được track), tự kiểm tra trước khi sửa.
