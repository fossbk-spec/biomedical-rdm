# Nguồn khóa học RDM mini

File `rdm-mini-course-source.md` là nguồn chân lý duy nhất của khóa học. Repo `biomedical-rdm-course` chỉ là bản render/web lấy nội dung từ nguồn này; file nguồn không được đưa vào `chapters` của `_quarto.yml` và không render như một chương của sách.

Quy trình sửa:

1. Sửa nội dung trong file nguồn này trước.
2. Đồng bộ sang repo khóa học bằng `scripts/sync_from_source.py` ở repo `biomedical-rdm-course`.
3. Ghi phiên bản nguồn bằng commit hash của repo khóa học.

Phiên bản nguồn hiện tại: `69c45b1a050205779056ad3e81b319d5def25695`.
